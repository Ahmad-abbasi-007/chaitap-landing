# ChaiTap - Garam Chai, Tap Karte Hi

A modern, responsive landing page for a chai delivery startup concept.

**Live Demo:** https://chaitap-landing.vercel.app/

### Why I Chose React + Tailwind?

**React:** I chose React because it is component-based. I broke the whole UI into small reusable components like Navbar, Hero, Features etc. This makes code clean and easy to manage.

**Tailwind CSS:** I used Tailwind because it makes responsive design very fast. I didn't have to write separate CSS files. Using classes like `md:flex` and `grid-cols-1 md:grid-cols-3` made the site responsive for mobile, tablet and desktop easily.
